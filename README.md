# loja-online-biquinis

Catálogo online de biquínis e moda praia da marca "Livia.Carvalho" (título da página: "Summer"). A compra é feita por contato no WhatsApp.

Demo: https://loja-online-biquinis.vercel.app (também publicado em https://joaoequer.github.io/loja-online-biquinis/)

## Funcionalidades

- Vitrine com vários modelos (aro meia taça, maiôs, conjuntos, cangas, calças, saia etc.), cada um com galeria de fotos, preço e tamanhos.
- Link de contato para compra via WhatsApp.
- Site estático, sem carrinho nem pagamento online.

## Tecnologias

HTML e CSS.

## Como rodar localmente

Sem build: abra `index.html` no navegador.

## Estrutura

- `index.html`, `styles.css` - página e estilos
- `beach.png` - logo
- Uma pasta por modelo (ex.: `maio-luna/`, `cangas-em-poliéster/`) com as fotos

## Status

Site pequeno de catálogo, mantido com atualizações de modelos e preços.
